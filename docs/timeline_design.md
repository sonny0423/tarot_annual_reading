# 流年能量週期時間軸設計文檔

## 概述
實作一個互動式時間軸，視覺化展示流年能量週期的關鍵階段，幫助使用者理解當前所處的能量位置。

## 關鍵日期計算

### 基準日期
- **去年生日**：`birthYear - 1` 年的 `birthMonth/birthDay`
- **今年生日**：`birthYear` 年的 `birthMonth/birthDay`
- **明年生日**：`birthYear + 1` 年的 `birthMonth/birthDay`
- **當前日期**：使用者瀏覽器的當前日期

### 關鍵階段
1. **流年生理期起始**：今年生日前4個月
   - 計算：`birthMonth - 4`（如果 < 1，則向前一年借位）
   - 意義：下一個流年能量開始醞釀的時期

2. **流年高峰期**：今年生日後6個月
   - 計算：`birthMonth + 6`（如果 > 12，則進位到下一年）
   - 意義：流年能量達到最高峰的時期

3. **暴風圈範圍**：高峰期前後2個月
   - 起始：高峰期 - 2個月
   - 結束：高峰期 + 2個月
   - 意義：流年能量影響最強烈的時期

## 視覺設計

### 時間軸結構
```
去年生日 ----[生理期起始]---- 今年生日 ----[高峰期]---- 明年生日
    |                           |      [當前位置]         |
    +---------------------------+---------------------------+
            上一個流年週期              當前流年週期
```

### 弧形設計
- 使用SVG繪製兩個連續的弧形
- 左弧：去年生日 → 今年生日
- 右弧：今年生日 → 明年生日
- 今年生日位於中心點

### 顏色編碼
- **生理期區域**：淺紫色（#E9D5FF）
- **高峰期區域**：深紫色（#A855F7）
- **暴風圈區域**：紅色漸變（#EF4444）
- **當前位置**：動態標記（閃爍效果）

### 標記點
- 去年生日：小圓點 + 日期標籤
- 今年生日：大圓點 + 日期標籤（中心）
- 明年生日：小圓點 + 日期標籤
- 生理期起始：菱形標記 + 日期標籤
- 高峰期：星形標記 + 日期標籤
- 當前位置：脈動圓點 + "今日"標籤

## 互動功能

### 點擊事件
- 點擊不同階段區域，顯示該階段的詳細說明
- 使用Dialog或Popover組件展示說明內容

### 說明內容
1. **生理期階段**
   - 標題：流年生理期（生日前4個月開始）
   - 說明：下一個流年能量開始醞釀，適合提前準備和規劃

2. **高峰期階段**
   - 標題：流年高峰期（生日後6個月）
   - 說明：流年能量達到最高峰，影響力最強，是關鍵決策和行動的時期

3. **暴風圈階段**
   - 標題：暴風圈（高峰期前後2個月）
   - 說明：流年能量影響最強烈，可能經歷重大變化或挑戰

## 技術實作

### 組件結構
```tsx
<FlowingYearTimeline
  birthDate={Date}
  currentDate={Date}
  onStageClick={(stage: string) => void}
/>
```

### 計算函數
```typescript
interface TimelineData {
  lastYearBirthday: Date;
  thisYearBirthday: Date;
  nextYearBirthday: Date;
  physiologicalPeriodStart: Date;
  peakPeriod: Date;
  stormCircleStart: Date;
  stormCircleEnd: Date;
  currentDate: Date;
  currentPosition: number; // 0-1之間，表示當前位置在時間軸上的百分比
}

function calculateTimelineData(birthDate: Date, currentDate: Date): TimelineData
```

### SVG繪製
- 使用 `<path>` 元素繪製弧形
- 使用 `<circle>` 元素繪製標記點
- 使用 `<text>` 元素添加日期標籤
- 使用CSS動畫實作當前位置的脈動效果

## 響應式設計
- 桌面版：完整顯示，寬度100%
- 平板版：縮小標籤字體，保持完整結構
- 手機版：簡化標籤，只顯示關鍵日期

## 無障礙設計
- 為所有標記點添加 `aria-label`
- 支援鍵盤導航（Tab鍵切換焦點）
- 提供文字版本的時間軸說明（用於螢幕閱讀器）
